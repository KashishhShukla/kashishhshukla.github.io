## ✨ Portfolio Key Features

- **Ambient Constellation Canvas:** High-performance particle physics network reacting smoothly to mouse proximity.
- **Dynamic Role Rotator:** Animated typing headline rotating between core technical specializations.
- **Interactive 3D Avatar Tilt:** Cursor-tracking perspective tilt with realistic depth and lighting.
- **Live Theme Accent Switcher:** 4 switchable color presets (*Electric Indigo*, *Cyber Cyan*, *Emerald Matrix*, *Cyber Violet*) updating CSS custom properties live and saved to `localStorage`.
- **Web Audio Micro-Sounds:** Native Web Audio API synthesizing subtle UI chimes on user interaction (with a mute toggle).
- **Interactive Dev Lab (Glassmorphism Sandbox):** Real-time playground allowing visitors to tweak blur, opacity, and borders with a 1-click **Copy CSS** tool.
- **Project Detail Modal Dialog:** Deep architecture breakdown, performance metrics, and repository links.
- **Stats Counter Ribbon:** Animated count-up numbers triggered on scroll via `IntersectionObserver`.
- **Responsive Contact Form:** Client-side validation, loading state spinner, and floating glass toast notification feedback.

## 💻 Running Locally

You can preview the website locally without needing any dependencies:

### Using Built-In PowerShell Server (Windows)
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8088
```
Then visit: `http://localhost:8088/`

### Using Python
```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000/`
